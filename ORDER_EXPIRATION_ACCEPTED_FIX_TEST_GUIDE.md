# ⏰ Accepted Order Expiration Fix - Test Guide

## 🎯 Цел
Тестване на поправката която не дава на приети заявки да експайрнат след 2 минути.

## 🐛 Проблемът (преди fix-а)
1. Клиент създава заявка (2-минутен timer)
2. Шофьор изпраща оферта
3. Клиент приема офертата → статус = 'accepted' 
4. Показва се панел "ОФЕРТА ПРИЕТА!" с име на шофьора
5. ❌ **След 2 минути**: Timer изтича → "Времето изтече" modal → панелът изчезва

## ✅ Решението (след fix-а)
- **File**: `src/hooks/client/useClientOrders.ts`
- **Logic**: Проверява статуса преди да експайрне заявката
- **Rule**: Само заявки в статус `['pending', 'searching', 'bidding']` могат да експайрнат
- **Protected statuses**: `['accepted', 'payment_pending', 'paid', 'in_progress', 'completed']`

## 🧪 Как да тествате

### 1. **Създайте заявка и приемете оферта**
1. Влезте като клиент и създайте заявка
2. Влезте като шофьор и изпратете оферта  
3. Върнете се при клиента и приемете офертата
4. Минете през payment процеса
5. ✅ Вижте панела "ОФЕРТА ПРИЕТА!" с име на шофьора

### 2. **Изчакайте да изтече времето**
1. Наблюдавайте timer-а в панела да намалява
2. Когато стигне 0:00, изчакайте 10-15 секунди
3. ✅ **НЯМА** да се появи "Времето изтече" modal
4. ✅ Панелът "ОФЕРТА ПРИЕТА!" **остава** видим
5. ✅ Името на шофьора **остава** показано

### 3. **Проверете console логовете**
Отворете console и търсете този лог:
```
⏰ Timer expired but order is active - not expiring: {
  orderId: "order_123",
  status: "accepted", 
  canExpire: false,
  willExpire: false,
  reason: "Order is accepted/paid/in-progress"
}
```

### 4. **Сравнете с необработена заявка**
За контрол тест:
1. Създайте друга заявка НО НЕ я приемайте
2. Оставете я в статус 'bidding' или 'searching'
3. Изчакайте 2 минути
4. ✅ Тази заявка ТРЯБВА да експайрне нормално
5. ✅ Трябва да се покаже "Времето изтече" modal

## 🎛️ Protected Order Statuses

Заявки с тези статуси **НЕ** експайрнат:
- ✅ `'accepted'` - Офертата е приета, чака се шофьорът
- ✅ `'payment_pending'` - Чака се плащане
- ✅ `'paid'` - Платена
- ✅ `'in_progress'` - В процес на изпълнение
- ✅ `'completed'` - Завършена

## 🎛️ Expirable Order Statuses  

Заявки с тези статуси **МОГАТ** да експайрнат:
- ⏰ `'pending'` - Чака се broadcast към шофьори
- ⏰ `'searching'` - Търси се шофьор
- ⏰ `'bidding'` - Получават се оферти

## 🐛 Troubleshooting

### Ако приета заявка все още експайрва:
1. Проверете console за логовете
2. Проверете дали статуса наистина е 'accepted'
3. Проверете дали `canExpire` е false в лога

### Ако необработени заявки НЕ експайрват:
1. Проверете дали статуса е в ['pending', 'searching', 'bidding']
2. Проверете дали `canExpire` е true в лога
3. Проверете дали има грешки при updateOrderStatus
