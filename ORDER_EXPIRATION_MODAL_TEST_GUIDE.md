# ⏰ Order Expiration Modal - Test Guide

## 🎯 Цел
Тестване на новия modal който се показва когато 2-минутната заявка изтече.

## ✅ Какво беше добавено

### Enhanced Order Expiration Flow
- **File**: `src/hooks/client/useClientOrders.ts`
- **Feature**: Automatic modal display when order expires
- **Message**: "Времето за получаване на оферти изтече. Можете да пуснете нова заявка ако все още имате нужда от помощ."

## 🧪 Как да тествате

### 1. **Създайте тестова заявка**
1. Отворете приложението като клиент
2. Натиснете "Заяви помощ" 
3. Попълнете детайлите и натиснете "Изпрати заявка"
4. ✅ Заявката се създава със 2-минутен timer

### 2. **Наблюдавайте countdown-а**
1. Гледайте ActiveOrderPanel с timer
2. Виждате "⏱ Остават 2:00", "1:59", "1:58"...
3. Timer се обновява всяка секунда
4. ✅ Timer работи правилно

### 3. **Изчакайте изтичане на времето**
1. Изчакайте timer-ът да стигне "0:00"
2. Автоматично трябва да се покаже modal с:
   - 📱 **Title**: "⏰ Времето изтече"
   - 📝 **Message**: "Времето за получаване на оферти изтече..."
   - 🔶 **Icon**: Orange time icon
   - 🔘 **Buttons**: "Разбрах" и "Нова заявка"

### 4. **Тествайте бутоните**

#### Option A: "Разбрах"
1. Натиснете "Разбрах"
2. ✅ Modal се затваря
3. ✅ Няма активна заявка (ActiveOrderPanel изчезва)
4. ✅ "Заяви помощ" бутонът е достъпен отново

#### Option B: "Нова заявка"  
1. Натиснете "Нова заявка"
2. ✅ Modal се затваря
3. ✅ Може веднага да натиснете "Заяви помощ"
4. ✅ Нова заявка се създава без проблеми

### 🔧 Технически детайли:
- **Timer**: 2 минути (120,000 ms)
- **Frequency**: Обновява всяка секунда
- **Database**: Order status → "expired"
- **UI**: ActiveOrderPanel се скрива
- **User Experience**: Clear notification + action options

## 🐛 Troubleshooting

Ако modal-ът НЕ се появи:
1. Проверете console за грешки
2. Вижте дали заявката наистина е маркирана като "expired"
3. Проверете дали `setCustomModal` function е правилно предадена

Ако timer-ът не работи:
1. Проверете дали `activeOrder.expiresAt` е правилно зададен
2. Вижте console за грешки при `updateOrderStatus`

## 📱 Edge Cases за тестване

1. **Приложението е минимизирано**: Timer трябва да продължи да работи
2. **Получена оферта преди изтичане**: Modal НЕ трябва да се появи
3. **Мрежата спре**: Modal трябва да се появи въпреки мрежови проблеми
4. **Множество заявки**: Само активната заявка трябва да има timer
