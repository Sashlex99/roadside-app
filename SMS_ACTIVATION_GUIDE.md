# 📱 Ръководство за активиране на SMS верификация

## 🎯 Кога да активираме реалната SMS верификация?

### 📅 **Препоръчителен график:**

| Фаза | Режим | Кога | Защо |
|------|-------|------|------|
| **Development** | `demo` | Сега | Безплатно тестване, бързо итериране |
| **Alpha Testing** | `demo` | Вътрешни тестове | Контролирана среда |
| **🎯 Beta Testing** | `beta` | **ПРЕПОРЪКА** | Реални потребители, малки разходи |
| **Production** | `production` | Публично пускане | Пълна функционалност |

## 🚀 **Моята препоръка: Активирайте в Beta фазата**

### ✅ **Защо Beta е идеалният момент:**
- 🧪 **Реални тестове** с истински потребители и телефони
- 💰 **Контролирани разходи** - малко beta тестери = малко SMS-и  
- 🐛 **Откриване на проблеми** преди production
- 📱 **Тестване на оператори** - A1, Vivacom, Yettel
- 🔧 **Време за поправки** ако нещо не работи
- 📊 **Събиране на данни** за SMS delivery rates

### 💰 **Ориентировъчни разходи:**
- **Beta (20 тестери × 2 регистрации):** ~2.40 лв (40 SMS × 0.06 лв)
- **Production (стотици потребители):** Значително повече

## 🔧 **Как да активираме SMS верификацията:**

### **Стъпка 1: Избор на SMS провайдер**

#### 🇧🇬 **SMS.bg (Препоръчително за България)**
- **Цена:** ~0.06 лв на SMS
- **Предимства:** Български, лесен API, добра поддръжка
- **Регистрация:** https://sms.bg

#### 🏢 **VivaKom (За корпоративни клиенти)**
- **Цена:** Договорна  
- **Предимства:** Висока надеждност, корпоративни пакети
- **Подходящ за:** Големи приложения

#### 🌍 **Twilio (Международен)**
- **Цена:** ~$0.075 на SMS
- **Предимства:** Глобално покритие, отлично API
- **Подходящ за:** Международни приложения

### **Стъпка 2: Регистрация и API ключове**

1. **Регистрирайте се** при избрания провайдер
2. **Получете API credentials:**
   - API Key
   - Username (ако се изисква)
   - От къде да се изпращат SMS-ите

### **Стъпка 3: Конфигуриране на средата**

Копирайте `sms.env.example` и създайте `.env` файл:

```bash
# За Beta тестване
SMS_MODE=beta
SMS_PROVIDER=sms.bg
SMS_API_KEY=your-real-api-key
SMS_USERNAME=your-username
SMS_FROM_NAME=PutnaPomosht
```

### **Стъпка 4: Тестване на конфигурацията**

```javascript
// Създайте test файл
// test-sms-real.js

const { sendSMSVerificationCode } = require('./src/services/smsService');

async function testRealSMS() {
  try {
    // Сложете своя тестов номер
    await sendSMSVerificationCode('0888123456');
    console.log('✅ SMS тест успешен!');
  } catch (error) {
    console.error('❌ SMS тест неуспешен:', error);
  }
}

testRealSMS();
```

## 📋 **Етапи на активиране:**

### **Фаза 1: Demo → Beta (СЕГА)**

**Какво да направите:**
1. ✅ Регистрирайте се в SMS.bg
2. ✅ Получете API ключове
3. ✅ Конфигурирайте `.env` с `SMS_MODE=beta`
4. ✅ Тествайте с няколко реални номера
5. ✅ Изпратете beta версия на тестери

**Конфигурация:**
```env
SMS_MODE=beta           # Реални SMS + debug логове
SMS_PROVIDER=sms.bg
SMS_API_KEY=real-key
SMS_FROM_NAME=PutnaPomosht
```

### **Фаза 2: Beta → Production (По-късно)**

**Конфигурация:**
```env
SMS_MODE=production     # Само реални SMS, без логове
SMS_PROVIDER=sms.bg
SMS_API_KEY=production-key
SMS_FROM_NAME=PutnaPomosht
```

## 🛡️ **Сигурност и лимити:**

### **Текуща защита в кода:**
- ✅ Rate limiting (10 SMS/час, 50 SMS/ден)
- ✅ Phone number валидация
- ✅ Код експирация (5 минути)
- ✅ Environment-based конфигурация

### **Допълнителни мерки за production:**
```typescript
// Добавете в production
const SMS_RATE_LIMITS = {
  perIP: { max: 5, window: 3600 }, // 5 SMS на час per IP
  perPhone: { max: 3, window: 3600 }, // 3 SMS на час per телефон
  dailyBudget: 50, // Макс 50 лв на ден
};
```

## 📊 **Мониториране и analytics:**

### **Какво да следите:**
- 📈 **Delivery rate** - процент доставени SMS-и
- 💰 **Разходи** - дневни/месечни
- 🔄 **Retry attempts** - неуспешни опити
- 📱 **Operator distribution** - A1, Vivacom, Yettel

### **Логове за мониториране:**
```typescript
// Beta режим логира:
console.log(`📱 BETA: Изпращам реален SMS код за ${phone}: ${code}`);
console.log(`✅ SMS изпратен успешно до ${phone} чрез ${provider}`);

// Production режим логира:
console.log(`📱 Изпращам SMS код за ${phone}`);
console.log(`✅ SMS изпратен успешно до ${phone} чрез ${provider}`);
```

## 🚨 **Backup план:**

### **Ако SMS провайдерът спре:**
1. **Backup провайдер** - конфигурирайте втори провайдер
2. **Fallback механизъм** - автоматично превключване
3. **Email верификация** - алтернативен метод

### **Конфигурация за backup:**
```env
# Primary provider
SMS_PROVIDER=sms.bg
SMS_API_KEY=primary-key

# Backup provider  
SMS_BACKUP_PROVIDER=twilio
SMS_BACKUP_API_KEY=backup-key
```
